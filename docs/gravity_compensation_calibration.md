# OpenArm 重力补偿比例的辨识与验证方案

本文是针对当前项目代码制定的实验方案，尚未开展新的真机标定，不包含测得的最优比例或实验结论。原先使用的 `gravity_scale=0.5` 应记录为预实验设置。

## 1. 区分模型标定和部署选参

以 `g_model(q)` 表示抵消重力所需的模型关节力矩（与 KDL `JntToGravity` 的使用约定一致），当前节点输出为：

\[
\tau_{ff,j}=\operatorname{clip}(\alpha_{eff}(t)g_{model,j}(q),-L_j,L_j).
\]

`alpha_eff(t)` 受启动/参数修改后的 ramp 影响，不能把 ramp 中的数据当作目标比例已经生效的数据。底层电机同时接收位置/速度目标、PD 增益和前馈，概念上是：

\[
\tau_{act}\approx K_p(q_d-q)+K_d(\dot q_d-\dot q)+\tau_{ff}.
\]

两种需要分别回答的问题：

1. **模型标定：** 用哪个比例能最好地预测真实重力负载？若模型、单位和执行器映射完全正确，理想模型比例是 1。
2. **部署选参：** 在模型误差、输出限幅和指定任务条件下，哪个已验证比例满足跟踪误差、振动、温度等约束？这个值可以不同于模型标定结果。

理论上应补足模型重力，不等于已经证明当前实机可以直接使用 1。`0.5` 也不能仅凭“能停住”证明正确：剩余力矩可能来自位置 PD 或静摩擦。

## 2. 本项目已经确认的实现条件

- 动力学计算位于 `ros2_ws/src/openarm_ros2/openarm_gravity_comp/src/arm_dynamics.cpp`，使用 URDF 和 KDL 计算 7 关节重力矩。
- 当前主要 launch 位于 `OpenarmXR/openarm_ros2/openarm_bringup/launch/openarm.bimanual.launch.py`，配置的前馈限幅为 `[2,2,2,2,0.5,0.5,0.5] Nm`。这不是电机总输出力矩限制；PD 部分另行产生力矩。
- 节点源码自身的默认限幅与 launch 的覆盖值不同。实验应保存实际生效参数，不能只引用源码默认值。
- `OpenarmXR/openarm_ros2/openarm_hardware/src/openarm_simple_hardware.cpp` 读取电机反馈力矩并导出 effort 接口，具备进一步记录的基础；仍需在运行时检查 `/joint_states.effort` 是否完整、有效、单位正确。
- 目前 `openarmx_bimanual_vla30_test` 只有位置 state/action、图像及索引/时间信息，没有记录力矩反馈、实际增益和前馈限幅状态，不足以直接完成这里的力矩辨识。
- KDL 当前使用到 `hand_tcp` 的串联链。重力包说明指出，活动手指分支不计入该 7 轴链。建模核查应确认手指、线缆及外部负载是否被正确等效计入，不能直接把所有偏差归入比例。

## 3. 标定前核查

1. 对齐实际机械臂版本、URDF、安装方向、关节顺序、零位和正方向。
2. 确认质量、质心及末端负载；静态重力主要依赖这些量，不能用它单独辨识全部转动惯量。
3. 核对电机型号、固件参数、反馈解码和命令编码使用的力矩量程。程序中 DM4340 与 DM4310 的映射量程不同，不能用另一种电机的量程解码后回归。
4. 对关键关节使用已知负载/几何力臂或参考力矩测量，核对反馈的比例、单位和符号。若只相信电机内部估算而没有独立校准，论文应称为“基于驱动器力矩估计的标定”，保留其不确定性。
5. 固定夹爪状态、负载、控制增益和热状态。若要推广到不同负载，应分别验证或显式建立负载模型。

## 4. 数据采集设计

推荐先做多姿态静态/准静态辨识。下列数量是本项目的起始实验设计建议，不是行业规定或已经完成的实验。

- 每条手臂选取约 15–30 个可安全保持的姿态，覆盖实际作业区域中不同的肩/肘力臂，不集中在单一姿态附近。
- 每个姿态从不同方向缓慢接近并重复至少 3 次；等待位置、速度和反馈力矩稳定以及 ramp 完成后，保存稳定窗口。
- 固定正常位置控制与已验证的保守补偿设置即可采集总力矩反馈，无需为了辨识关闭位置控制或解除已有力矩限幅。
- 记录实际关节角后，在这些实际角度上计算模型重力矩；不要用目标角度替代。
- 无未知外部接触、无人托臂时的数据用于无接触回归。若必须通过接触支撑，应测量接触力并在动力学方程中扣除，不能把支撑数据直接当作自由悬空重力负载。
- 用实际速度/加速度和力矩稳定性判定是否准静态；阈值应结合噪声、重复性和运动时间尺度确定并报告。
- 同一稳定窗口的连续帧高度相关，应聚合为姿态/重复实验样本，不把数千帧当作数千次独立实验。

建议记录字段：

| 字段 | 用途 |
| --- | --- |
| `pose_id, repeat_id, arm, joint_name, timestamp` | 分组、对齐与追溯 |
| `q, dq, q_des, dq_des`（rad、rad/s） | 姿态、运动状态和控制误差 |
| `tau_feedback_nm` | 校核后的电机总力矩估计 |
| `g_model_raw_nm` | 未乘比例、未限幅的模型重力矩 |
| `tau_ff_applied_nm` | 真正施加的前馈，含 ramp、限幅影响 |
| `scale_target, scale_effective, torque_limit_nm` | 区分配置值和实际输出 |
| `kp, kd, payload_id, gripper_state, temperature` | 控制实验条件和混杂因素 |
| `is_saturated, state_age, data_valid` | 排除不适合的样本并报告工作范围 |

节点当前的 preview 话题已经是缩放和限幅后的前馈，不是 `g_model_raw`，也不是独立测得的真实重力矩。未限幅模型量应通过同一份 URDF 和计算器离线求得，或将来新增独立诊断输出。

### 静摩擦处理

从两个方向到达同一姿态可揭示迟滞，但静摩擦并不必然因简单平均就精确消失。

更进一步可以在相同姿态附近，以匹配的低速正/反向路径记录总力矩：在运动惯性项足够小、路径姿态匹配、摩擦近似关于速度为奇函数的前提下，`(tau_plus(q)+tau_minus(q))/2` 可近似减弱库仑和黏性摩擦影响。需要对齐实际 q，并检查反向差异，不能默认这对所有减速器都成立。

## 5. 用加权最小二乘估计比例

令第 k 个姿态、第 j 个关节的模型重力为 `g_jk`，清理后的实际保持力矩估计为 `t_jk`。先拟合一个全局比例，并可引入每关节常偏置：

\[
 (\hat\alpha,\hat b)=\arg\min_{\alpha,b}
 \sum_{j,k}w_{jk}\left[t_{jk}-\alpha g_{jk}-b_j\right]^2.
\]

偏置只描述固定偏差，不能替代姿态相关的摩擦、错误零位或错误质心模型。是否引入偏置，应比较留出数据上的效果。

不包含偏置且模型假设成立时：

\[
\hat\alpha=\frac{\sum_{j,k}w_{jk}g_{jk}t_{jk}}
{\sum_{j,k}w_{jk}g_{jk}^2}.
\]

加入每关节偏置时，先按关节计算加权均值，对 `g_jk` 和 `t_jk` 分别去均值，再用上式拟合去均值后的量，最后恢复 `b_j`。权重可以来自重复实验的力矩噪声方差，并结合预先声明的任务重要性。

需要报告：

- 使用的样本范围、权重、数据清理规则和模型假设。
- 设计矩阵的秩、条件数，以及模型重力的变化范围。重力矩接近零或几乎不随姿态变化的关节，不能可靠估计比例；不要直接做逐样本 `t/g` 后平均。
- 按姿态/实验组重采样得到的置信区间，而不是把相关帧当作独立样本得到过窄区间。
- 残差是否随姿态、运动方向、温度和手臂变化。
- 若估计值为负、明显偏离合理范围、或超出代码允许范围，先排查模型/量纲/反馈映射；不应直接把估计值截断后宣称标定成功，更不能自动应用到真机。

只有明确知道前馈和模型关系时，才能从前馈命令中构造额外量。把 `tau_ff=alpha*g_model` 当作观测 t 再拟合，只会得到原先设置的 alpha，是循环论证。

若无法获得可信的总力矩反馈，可在已确认 MIT PD 关系、实际增益和前馈的前提下，利用 `Kp*(q_des-q)+Kd*(dq_des-dq)+tau_ff_applied` 估计总作用力矩；但这是依赖执行器模型的间接方法，受摩擦、增益误差及饱和影响，证据强度低于独立校核后的力矩测量。

## 6. 留出验证与部署选择

按姿态划分辨识集和留出集，例如 70%/30%。同一姿态的相邻帧不能同时落入两边。比例是实验设计示例，可随样本数量调整。

先检查留出集的力矩预测残差，再在固定增益、负载和匹配任务轨迹下验证部署表现：

| 指标 | 含义 |
| --- | --- |
| 力矩预测 RMSE / 每关节残差 | 模型对真实负载的解释能力 |
| 静态关节保持误差 | 对作业区域内姿态的补偿效果 |
| `Kp*(q_des-q)` 的 RMS | 位置反馈仍承担的近似力矩，需增益映射可信 |
| 振动幅值、超调和跟踪 RMSE | 部署后的动态表现 |
| 前馈限幅比例 | 标量 alpha 实际能发挥作用的范围 |
| 温度和驱动器状态 | 部署约束，结合实验时长和重复实验报告 |

同一无接触静态姿态下，抵消真实重力所需的总力矩大致固定。重力前馈主要重新分配前馈与 PD 的贡献，因此不能把“静态总电流最小”直接作为理论最优标准，也不能保证补偿后保持电流必然下降。

前馈饱和时，提高 alpha 可能不再增加实际前馈。应报告该姿态的限幅状态；如果研究部署最优值，应使用包含 `clip` 和 ramp 的实际控制律评估，不能套用未限幅比例模型来证明部署效果。不要为获得标定曲线而解除已有硬件保护。

最终部署值可在**已经验证可行**的候选范围内，按照事先声明的目标（如最小保持误差）和约束（如振动、温度、限幅比例）选择，并报告重复实验的离散程度。它是指定工作域和任务下的选参结果，不是所有姿态、载荷和速度下的全局最优证明。

## 7. 若单比例不够

如果左右臂或各关节的最佳斜率明显不同，不应靠一个 alpha 掩盖问题。先检查模型和力矩映射；在数据充分且可辨识时，可以比较左右臂分别标定、逐关节比例等更丰富模型，但当前节点只提供一个公共 `gravity_scale`，应用这些方案需要另行改代码和验证。

更物理的方法是构造静态重力回归：

\[
\tau_g(q)=Y_g(q)\theta,
\]

辨识可观测的质量和质量一阶矩组合，并加入 CAD 先验、正质量、合理质心范围等约束。静态重力数据不能唯一恢复每个连杆的全部惯性参数；应检查秩并只辨识可观测组合。对于本科/中期后阶段，先完成“单比例辨识 + 留出验证 + 模型局限说明”通常已经能形成完整证据链。

## 8. 可用于答辩的表述

当前可以如实表述：

> 前期通过逐级调参完成了系统联调，50% 是预实验设置，尚未证明其最优。后续将以 URDF 重力模型为基础，通过多姿态力矩数据进行加权最小二乘辨识，处理静摩擦和测量不确定性，并在独立姿态和指定遥操作任务上验证保持误差、振动和输出限幅情况，确定具有明确适用条件的补偿参数。

实验完成后，应填写实际比例、置信区间、留出集误差、对照组表现和适用负载范围。不要提前将计划表述为已完成结果。
