下面是当前“左臂实机 + VR + 2% 重力补偿”的开机启动指南。右臂零件缺失期间保持断电，不连接 `can0`，全程只使用左臂 `can1`。

## 0. 首次或代码更新后编译

```
cd ~/OPENARM/OpenarmXR

unset AMENT_PREFIX_PATH COLCON_PREFIX_PATH CMAKE_PREFIX_PATH
unset PYTHONPATH LD_LIBRARY_PATH
source /opt/ros/humble/setup.bash

colcon build \
  --base-paths ~/OPENARM/ros2_ws/src/openarm_ros2/openarm_gravity_comp \
  --packages-select openarm_gravity_comp \
  --symlink-install

colcon build \
  --packages-select openarm_bringup \
  --symlink-install
```

日常使用不需要重复编译。

## 1. 开机与硬件检查

1. Pico、电脑、左臂电源启动。
2. 右臂保持断电。
3. 确认左臂接在 `can1`。
4. 机械臂附近保持空旷，准备随时扶稳或断电。

配置 CAN FD：

```
sudo ip link set can1 down
sudo ip link set can1 type can bitrate 1000000 \
  dbitrate 5000000 fd on restart-ms 100
sudo ip link set can1 up

ip -details link show can1
```

应看到：

```
can <FD>
bitrate 1000000
dbitrate 5000000
state ERROR-ACTIVE
```

可选通信检查：

```
source /opt/ros/humble/setup.bash
source ~/OPENARM/OpenarmXR/install/setup.bash

openarm-can-cli -i can1 discover --max-id 8
```

## 2. Pico 网络设置

电脑查询当前 Wi-Fi IP：

```
ip -4 addr show wlp5s0
```

在 Pico 的 OpenArmX VR APK 中：

```
ROS PC IP Address: <电脑 wlp5s0 的 IPv4 地址>
UDP Port: 5100
```

例如此前网络下是：

```
192.168.31.252:5100
```

每次电脑切换 Wi-Fi 或重启后都重新确认 IP。Pico 必须与电脑处于同一局域网，保持 APK 前台并进入 VR 会话。

## 3. 启动左臂 2% 实际补偿

终端 1：

```
unset PYTHONPATH LD_LIBRARY_PATH
source /opt/ros/humble/setup.bash
source ~/OPENARM/OpenarmXR/install/setup.bash

ros2 launch openarm_bringup openarm.left.launch.py \
  use_fake_hardware:=false \
  can_interface:=can1 \
  enable_gravity_compensation:=true \
  apply_gravity_compensation:=true \
  gravity_scale:=0.02 \
  gravity_ramp_duration_s:=10.0
```

启动后左臂会以约 10 秒回到零位。期间不要按 Grip、不要触碰机械臂。

确认控制器和实际补偿输出：

```
ros2 control list_controllers
ros2 topic echo /left_forward_effort_controller/commands --once
```

应存在：

```
left_forward_position_controller active
left_forward_effort_controller   active
```

`gravity_scale:=0.02` 表示 2% 模型重力前馈。它和位置控制叠加，机械臂不会自行抬起，主要用于减小关节负担和改善跟随。

## 4. 启动左臂 VR 遥操

终端 2：

```
unset PYTHONPATH LD_LIBRARY_PATH
source /opt/ros/humble/setup.bash
source ~/OPENARM/OpenarmXR/install/setup.bash

ros2 launch openarmx_teleop_vr \
  openarm_teleop_vr_left_real.launch.py
```

操作顺序：

1. Pico 进入 VR 会话。
2. 确认左手控制器追踪正常。
3. 按住左手 `Grip` 后，再缓慢移动左臂。
4. 松开 `Grip` 后，左臂保持当前位置。
5. 按左手 `B`，左臂回到零位。

首次只做小范围、低速的肘部和腕部运动。

## 5. 运行检查

```
timeout 20s ros2 topic hz /pico_left_controller/pose
timeout 20s ros2 topic hz /left_forward_position_controller/commands
```

目标是输入与命令稳定在约 50 Hz 以上，且不要反复出现 `0.5–1 s` 的 gap。若日志出现 `VR pose stream gap`，优先排查 Pico Wi-Fi、追踪丢失、APK 是否在前台和电脑 Wi-Fi 节能。

补偿输出可查看：

```
ros2 topic echo /gravity_compensation/left_effort
```

之前左肘微弯时，5% 预览中 J4 约为 `-0.0878 Nm`；因此当前 2% 实际输出约为 `-0.035 Nm`，属于保守起点。

## 6. 正常结束与紧急停止

正常结束：

1. 松开 Grip。
2. 按 `B` 回零，等待机械臂稳定。
3. `Ctrl+C` 停止 VR 终端。
4. `Ctrl+C` 停止左臂 bringup 终端。
5. 硬件节点会禁用左臂电机，再关闭左臂电源。

若出现反向拉扯、振荡、异响、突然跳动或 Pico 数据中断：

```
立即 Ctrl+C 停止 bringup，必要时直接切断左臂电源。
```

当前 2% 已完成左臂模型、力矩通路和实机低比例验证。保持这个比例运行，等 VR 输入 gap 稳定后，再考虑升到 5%。
