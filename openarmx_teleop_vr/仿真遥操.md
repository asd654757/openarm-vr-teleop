# Pico 4 → OpenArm 仿真遥操作流程

本流程只启动 **fake hardware 仿真**，不连接 CAN 和实体机械臂。

## 1. 电脑开机后连接 Wi-Fi

确保电脑和 Pico 4 连接同一个 Wi-Fi。

查看电脑 IP：

```
ip -4 addr show wlp5s0
```

找到类似：

```
inet 192.168.31.100/24
```

电脑 IP 可能在重启或切换 Wi-Fi 后变化，每次使用前都要确认。

## 2. Pico 端准备

1. 打开 Pico 4。
2. 连接与电脑相同的 Wi-Fi。
3. 打开已安装的 OpenArmX VR APK。
4. 在 VR 界面设置电脑 IP：

```
ROS PC IP Address: 192.168.31.100
```

端口固定为：

```
5100
```

一般默认就是5100

如果没有出现 IP 输入界面：

```
Pico 设置
→ 应用管理
→ OpenArmX VR
→ 清除应用数据
→ 重新打开
```

## 3. 一键启动完整仿真

电脑打开终端 1：

```
source /opt/ros/humble/setup.bash
source ~/OPENARM/OpenarmXR/install/setup.bash

ros2 launch openarmx_teleop_vr openarm_teleop_vr_sim.launch.py
```

该命令会同时启动：

```
OpenArm fake hardware
ros2_control
左右 forward position controller
VR UDP bridge
Pinocchio IK
robot_state_publisher
RViz
```

正常日志包括：

```
Listening for controller poses on 0.0.0.0:5100
Pinocchio teleop core initialized successfully
Node initialized - control rate: 100.0 Hz
```

该终端必须保持运行。

## 4. 开始遥操作

进入 Pico APK 的 VR 会话，然后：

- 按住右侧 `Grip` 并移动右手：控制右臂
- 按住左侧 `Grip` 并移动左手：控制左臂
- 松开 `Grip`：停止对应机械臂跟随
- `Trigger`：控制对应夹爪
- 右手柄 `B`：双臂回到零位
- 左手柄 `Y`：执行举手动作

建议回零时：

```
松开左右 Grip
→ 停止移动手柄
→ 按一次右手柄 B
```

## 5. 检查 Pico 数据

电脑打开终端 2：

```
source /opt/ros/humble/setup.bash
source ~/OPENARM/OpenarmXR/install/setup.bash
```

检查右手柄位姿：

```
ros2 topic hz /pico_right_controller/pose
```

检查 Grip：

```
ros2 topic echo /pico_right_controller/grip
```

按下 Grip 后数值应超过：

```
0.5
```

## 6. 检查仿真控制

检查控制器：

```
ros2 control list_controllers
```

应看到三个控制器均为 `active`：

```
joint_state_broadcaster
left_forward_position_controller
right_forward_position_controller
```

检查机器人状态：

```
ros2 topic hz /joint_states
```

检查右臂 IK 命令：

```
ros2 topic hz /right_forward_position_controller/commands
```

检查左臂 IK 命令：

```
ros2 topic hz /left_forward_position_controller/commands
```

发布控制命令需要同时满足：

```
Pico pose 持续更新
Grip > 0.5
/joint_states 持续更新
```

## 7. 结束仿真

先松开左右 Grip，再按 `B` 回零。确认机械臂回零后，在启动终端按：

```
Ctrl+C
```

等待所有节点正常退出后再关闭终端。

## 常见问题

切换 Wi-Fi 后无法控制：

```
ip -4 addr show wlp5s0
```

将新的电脑 IP 重新填写到 Pico APK。

检查 UDP bridge：

```
ss -lunp | grep 5100
```

检查网络数据：

```
sudo env -u LD_LIBRARY_PATH \
  /usr/bin/tcpdump -ni wlp5s0 udp port 5100
```

不要同时运行单独 bridge 和完整仿真，否则会争用 UDP `5100`。
