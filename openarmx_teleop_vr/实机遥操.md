# OpenarmXR 双臂 VR 实机遥操作流程

## 一、系统链路

```
Pico 4 OpenArmX APK
→ Wi-Fi UDP 5100
→ OpenarmXR Bridge
→ ROS2 手柄话题
→ Pinocchio 双臂 IK
→ forward_position_controller
→ SocketCAN FD
→ OpenArm 双臂实机
```

当前硬件映射：

```
can0 = 右臂
can1 = 左臂
仲裁速率 = 1 Mbps
数据速率 = 5 Mbps
电源 = 48V
```

## 二、电脑与机械臂开机

1. 启动电脑。
2. 连接 Wi-Fi。
3. 连接两个 PCAN-USB FD。
4. 检查 CAN 线和 48V 电源。
5. 释放急停。
6. 开启机械臂 48V 电源。
7. 暂时不要打开 Pico APK，不要按 Grip。

检查 PCAN：

```
lsusb | grep -Ei '0c72|PCAN|PEAK'
ip -br link show type can
```

## 三、配置 CAN FD

```
source /opt/ros/humble/setup.bash
source ~/OPENARM/OpenarmXR/install/setup.bash

openarm-can-configure-socketcan-4-arms \
  -fd -b 1000000 -d 5000000
```

没有 `can2/can3` 时，相关报错可以忽略。

检查：

```
ip -details link show can0
ip -details link show can1
```

正常状态：

```
can <FD>
state ERROR-ACTIVE
bitrate 1000000
dbitrate 5000000
berr-counter tx 0 rx 0
```

## 四、确认无残留进程

```
ps -ef | grep -E \
  '[r]os2_control_node|[o]penarmx_teleop|[r]os2 launch'
```

不要同时运行仿真和实机节点。

## 五、启动 OpenArm 双臂底层

启动前保证：

- 双臂靠近安全零位
- 周围无人和障碍物
- Pico Grip 全部松开
- 急停可立即触发

终端 1：

```
source /opt/ros/humble/setup.bash
source ~/OPENARM/OpenarmXR/install/setup.bash

ros2 launch openarm_bringup openarm.bimanual.launch.py \
  use_fake_hardware:=false \
  robot_controller:=forward_position_controller \
  right_can_interface:=can0 \
  left_can_interface:=can1
```

驱动会使能电机，并在约 10 秒内回到官方零位。

## 六、检查实机底层

另开终端：

```
source /opt/ros/humble/setup.bash
source ~/OPENARM/OpenarmXR/install/setup.bash

ros2 control list_controllers
```

应看到：

```
joint_state_broadcaster           active
left_forward_position_controller active
right_forward_position_controller active
left_gripper_controller           active
right_gripper_controller          active
```

检查反馈：

```
ros2 topic hz /joint_states
```

如果出现 CAN 丢包、BUS-OFF 或关节异常，不启动 VR。

## 七、启动 OpenarmXR 遥操

终端 2：

```
source /opt/ros/humble/setup.bash
source ~/OPENARM/OpenarmXR/install/setup.bash

ros2 launch openarmx_teleop_vr \
  openarm_teleop_vr_real.launch.py
```

正常日志：

```
Listening for controller poses on 0.0.0.0:5100
Pinocchio teleop core initialized successfully
Using 7-DoF arm commands with separate gripper controllers
```

## 八、启动 Pico 4

查询电脑 Wi-Fi IP：

```
ip -4 addr show wlp5s0
```

在 Pico 中：

1. 连接与电脑相同的 Wi-Fi。
2. 打开 OpenArmX APK。
3. 填写电脑 IP。
4. UDP 端口使用 `5100`。
5. 进入 VR 会话。

检查数据：

```
ros2 topic hz /pico_left_controller/pose
ros2 topic hz /pico_right_controller/pose
```

## 九、手柄操作

```
左 Grip       左臂跟随
右 Grip       右臂跟随
左 Trigger    左夹爪
右 Trigger    右夹爪
右手柄 B      双臂回零
左手柄 Y      举手动作
```

首次操作顺序：

1. 先只按一侧 Grip。
2. 小幅缓慢移动。
3. 检查方向和比例。
4. 松开 Grip，确认机械臂停止跟随。
5. 单臂确认正常后再测试双臂。

## 十、正常停机

1. 松开左右 Grip。
2. 按右手柄 `B`。
3. 等待双臂完成回零。
4. 先在 VR 遥操终端按 `Ctrl+C`。
5. 再在实机底层终端按 `Ctrl+C`。
6. 确认左右 hardware 均显示 `deactivated`。
7. 关闭机械臂 48V 电源。

## 十一、紧急处理

发生跳动、方向错误或通信异常时：

1. 立即松开 Grip。
2. 按下急停。
3. 关闭 VR 遥操进程。
4. 关闭实机底层进程。
5. 必要时关闭 48V 电源。
6. 检查：

```
ip -s -details link show can0
ip -s -details link show can1
```

出现 `ERROR-PASSIVE` 或 `BUS-OFF` 时，不继续运行遥操。
